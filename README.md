# moysklad-shop-bot

Каркас Telegram-витрины для поиска товаров и проверки остатков в МойСклад. В [config.py](config.py) есть настройки витрины, лимиты выдачи и примеры карточек магазинов. В [moysklad.py](moysklad.py) описано, как поиск должен объединять товары с остатками по складам.

Запросы товаров и остатков, подтверждение возраста, меню, поиск и пагинация оставлены заглушками в [moysklad.py](moysklad.py) и [handlers.py](handlers.py).

## Запуск

[main.py](main.py) содержит точку входа aiogram. Для работы витрины нужны реализации обработчиков и запросов к МойСклад. Зависимости перечислены в [requirements.txt](requirements.txt), имена переменных окружения в [.env.example](.env.example).
